# GL.iNet GL-MT300N-V2 (Mango)

- SoC: MediaTek MT7628NN; MIPS
- Typical configuration: 128 MiB RAM; 16 MiB SPI NOR flash
- M5: SoC registers, UART, RAM, SPI NOR and interrupts
- M6: U-Boot, Ethernet and OpenWrt / MikroWrt / PocketBox boot tests
- Wi-Fi and USB are later milestones, not prerequisites for the first UART boot.

Document actual hardware revision and flash partitions before mounting vendor images.
